## Free plan import limit

Free users can import up to **5 recipes per week**. A recipe only counts toward that limit when you tap **Save** — previewing without saving does not use a slot. Every recipe you save is yours to keep — recipes don't expire, and reaching the weekly limit only affects new imports. You can keep viewing, organizing, editing, searching, and cooking from everything already in your library.

Once you have used all 5, you cannot import any more recipes until a slot frees up. [Souschef Plus](/billing/subscription-benefits) removes the weekly import limit. See [How import quota works](/billing/how-import-quota-works) and [Recipe import limits](/billing/import-limits) for details.
