<Tip>
  **Every recipe you import is yours to keep.** Free users can import up to **5 recipes per week**. A recipe only counts toward that limit when you tap **Save**. Reaching the limit only affects new imports — you can still view, organize, edit, search, and cook from everything already in your library. See [How import quota works](/billing/how-import-quota-works) for details.
</Tip>
